# BetterSpotifyRecs
Better Spotify Recs is a recommendation algorithm that takes in an playlist of songs to generate a new playlist of n songs.


Experiment 1:
Runtime test
Fixed input playlist. Graph numbers of songs generated vs runtime.

Experiment 2:
Quality test
Input a playlist, use the first 70% of the input songs to generate new songs.
Count the overlap of last 30% of the input songs with new songs generated.
