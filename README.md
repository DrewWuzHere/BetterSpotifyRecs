# BetterSpotifyRecs
Better Spotify Recs is a recommendation algorithm that takes in an playlist of songs to generate a new playlist of n songs.

Experiment 1:
Runtime test
Fixed input playlist. Graph numbers of songs generated vs runtime.

Experiment 2:
Quality test
Input a playlist, use every input songs others than the last 5 to generate new songs.
Count the overlap of last 5 unused input songs with new songs generated.
